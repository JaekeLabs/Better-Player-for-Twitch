# Support

This repository is the public support and issue tracker for Better Player for Twitch.

## Before reporting a problem

Please make sure:

1. You are using **Firefox desktop 142 or newer**.
2. Better Player is enabled in Firefox Add-ons Manager.
3. You have refreshed the Twitch tab after installing or updating the extension.
4. You are not running another extension that modifies Twitch's stream-level video-ad playback.
5. The problem still occurs after a normal page reload.

If the issue only occurs on one Twitch channel, mention that in the report.

## What to include in a bug report

Please include:

- Better Player version
- Firefox version
- Operating system
- Twitch page/channel where the issue occurred, when relevant
- Clear steps to reproduce the issue
- What you expected to happen
- What actually happened
- Whether the issue happens consistently or intermittently
- Whether another Twitch, ad-blocking, audio, or player-modifying extension is enabled

Screenshots are welcome when they help explain the problem.

## Sensitive information

**Never post Twitch cookies, OAuth/access tokens, authorization headers, session tokens, integrity values, passwords, or other account credentials.**

If diagnostic information contains anything that looks like a credential or session value, remove it before posting.

## Ad-related reports

Twitch controls when and how ads are delivered, so ad behavior can vary between channels, accounts, regions, and sessions.

For an ad-related issue, describe what you observed rather than posting account/session credentials. Helpful details include whether:

- a normal Twitch ad appeared;
- playback froze or buffered;
- video quality changed during the break;
- the stream recovered automatically afterward;
- the Better Player ad-status indicator appeared.

## Feature requests

Feature requests are welcome. Please describe the problem or workflow you want improved, not only the proposed implementation.
