## Alternate Player for Twitch.tv

Better Player for Twitch began as a native-player-focused fork of **Alternate Player for Twitch.tv** by Alexander Choporov (CoolCmd).

Inherited project code is distributed under the **BSD 3-Clause License**. The distributed Better Player extension package includes the applicable BSD 3-Clause license notice.

Better Player has removed the standalone Alternate Player runtime and retains only code that is still used by the native Twitch enhancement path.

## TwitchAdBlock / TwitchAdSolutions

The native Twitch video-ad handling component is derived from **scamorza/TwitchAdBlock**, which in turn derives from the TwitchAdSolutions/VAFT approach.

Upstream sources:

- TwitchAdBlock: https://github.com/scamorza/TwitchAdBlock
- Upstream baseline used for the integration: TwitchAdBlock `vaft.user.js` v2.2.3
- Upstream v2.2.3 commit: https://github.com/scamorza/TwitchAdBlock/commit/a1453021869b43870e30fac4c384d09b60bef435
- Original TwitchAdSolutions project: https://github.com/pixeltris/TwitchAdSolutions
